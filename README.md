# 🌐 MINTLINE — Global Currency Converter

### Money Without Borders.

MINTLINE is a modern, responsive currency converter built with React and Tailwind CSS. It allows users to convert currencies in both directions, swap currencies instantly, and view exchange-rate information through a clean and premium fintech-inspired interface.

🔗 **Live Demo:** https://exchangeflow-anku.netlify.app

---

## ✨ Features

- **Bidirectional Conversion** – Convert from one currency to another and edit either amount.
- **Instant Currency Swap** – Switch FROM and TO currencies with one click.
- **Real-Time API Fetching** – Fetch exchange-rate data from an external API.
- **Custom React Hook** – Manage currency data using a reusable `useCurrencyInfo` hook.
- **Dynamic Currency Selection** – Select currencies using interactive dropdowns.
- **Exchange Rate Information** – Display the conversion rate between selected currencies.
- **Responsive Design** – Works across desktop and mobile devices.
- **Modern Fintech UI** – Dark-themed interface with a clean, premium visual experience.

## ⚙️ Installation & Setup

Follow these steps to run MINTLINE locally.

**1. Clone the repository**

```bash
git clone https://github.com/AnkitSingh9933/mintline.git
```

**2. Navigate to the project directory**

```bash
cd mintline
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in browser**

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
